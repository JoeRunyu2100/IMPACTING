# IMPACTING
A System Dynamics Model on Multiple Vectors and VBDs transmissions

Files type description for the Vensim Software:
'.mdl' file - This is the vensim model file that shows the different variables used in the system dynamics development. This is the main file to use to know the different variables and equations that have been generated.
'.vdfx' file - this file contain the simulation data from running the vensim model. This file will always be created upon running the model.

Key Files currently in repository
1. Model Files
   i) 'Aedes Version Presentation2.mdl' - Model featuring the following components: Aedes life cycle, Aedes vector SEI dynamics for Dengue, Chikungunya and Yellow Fever, A human S.E.I.R dynamics of the 3 VBDs from Aedes, A livestock VBD reservoir system and A human socioeconomic component.
  ii) 'New EPI Aedes Months.mdl' - A newly created version of the model that focuses on modeling two aedes species, i.e Aedes Aegypti and Aedes Albopictus. The model contains the following components: 1) Vector life cycle dynamics, 2) Vector SEI and 3) Human SEIR.
iii) 'Socioeconomuc CLD.mdl' - a casual loop representation of the variables and their interaction, focusing on the socioeconomic aspect in an environment influenced by disease vectors and vector borne diseases.

3. Excel files
   a) Mombas Climate2015_2065.xlsx - Climatic data focuses on the coordinates for Mombasa county, Kenya. The Data sheet is read in the vensim model, used to calculate climate data influence on vectors growth over time.
   b) First Version variables.xlsx - List of the variables and equations used in the model 'Aedes version Presentation2.mdl'
   c) Updating Vensim variables.xlsx - Variables and equatoions found in the model:'New EPI Aedes Months.mdl'
